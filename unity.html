Coming from Unity

GameCraft reads Unity's file formats and implements a large part of its scripting API. This page explains what carries over and how to migrate a project.

Importing a project

  1. In Unity, export your assets as a .unitypackage, or keep the project folder.
  2. In GameCraft, choose Assets > Import Unity Project or Import Unity Package. You can also use gamecraft-cli unity-import.
  3. Check the import report in the Console. It lists what was converted, what was skipped and why.
  4. Press Play. Scripts compile against the compatibility layer and run in the engine.

What is imported

  • Scenes and prefabs, including nested prefabs, overrides and removed components
  • Materials (Standard and URP), animation clips and animator controllers
  • ScriptableObject assets, render textures, UI canvases and particle systems
  • Audio mixers and Localization package tables
  • Asset references, resolved through the GUIDs in .meta files

Scripting API

Scripts using the supported parts of UnityEngine compile without changes. This includes MonoBehaviour messages, GetComponent, transforms, coroutines, serialized fields, ScriptableObject, UnityEvent, physics, input and touch, cameras, materials, UI, scene management, Netcode for GameObjects, Addressables and Localization. A script that uses something unsupported fails to compile with an error naming the missing member.

using UnityEngine;

public class Spinner : MonoBehaviour
{
    [SerializeField] float speed = 90f;

    void Update()
    {
        transform.Rotate(0f, speed * Time.deltaTime, 0f);
    }

    void OnTriggerEnter(Collider other)
    {
        Debug.Log("Collected by " + other.name);
        Destroy(gameObject);
    }
}

Editor extensions

Scripts in Editor folders run inside the GameCraft editor. Custom inspectors, EditorGUILayout, editor windows, menu items and property drawers are supported. UI Toolkit editors, Handles and scene-view drawing are not.

Not supported

  • Precompiled .dll plugins and native libraries. Packages must ship C# source.
  • The Unity Asset Store and Unity online services. Assets exported as a .unitypackage can be imported.
  • iOS and console platforms.

The complete checklist, with the test that covers each item, is in UNITY_PARITY.md: 66 of 73 items are done, and the remaining 7 depend on outside accounts, hardware or proprietary services.
