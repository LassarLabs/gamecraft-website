News

Release notes and project updates. Detailed changes are in the changelog.

  • October 2026

    Live build sessions

    Start the editor with GAMECRAFT_LIVE_DIR set and it runs the commands written to a file in that folder: creating projects, objects, materials and scripts, saving and playing. Each command goes through the normal editor actions and can be undone. The Neon City demo shows what it can do.

  • October 2026

    GameCraft 0.3

    The largest release so far. It adds Unity project import and the UnityEngine and UnityEditor compatibility layers, post-processing, reflection and light probes, baked lighting, Shader Graph, LOD and occlusion culling, Timeline, virtual cameras, GPU particles, mesh editing, animation rigging, and export to Windows, Linux, Web, Android and OpenXR. It also adds a package registry, Addressables, an audio mixer, multiplayer and localization.

  • 2026

    GameCraft 0.2

    Physics joints, a character controller, 2D physics, skeletal animation, glTF, OBJ and FBX import, terrain, navigation, packages and a profiler.

  • 2026

    GameCraft 0.1

    The first version: the engine, the editor, C# scripting and game export.
