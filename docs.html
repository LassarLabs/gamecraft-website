Documentation

Getting started with GameCraft. The full manuals live in the repository.

Your first project

  1. Open GameCraft and choose New Project. Pick the 3D Core template.
  2. Choose GameObject > 3D Object > Cube and add a Rigidbody in the Inspector.
  3. Choose Assets > Create > MonoBehaviour Script and open it in the script editor.
  4. Press Play to run the scene.
  5. Choose File > Build Settings and click Build to export a standalone game.

Building from source

You need Node 22.19 or later, the stable Rust toolchain and the .NET 10 SDK. On macOS you also need the Xcode command-line tools.

git clone https://github.com/LassarLabs/gamecraft.git
cd gamecraft
npm install
source tools/env.sh
npm run dotnet:build
npm run tauri:dev

Command line

gamecraft-cli build <project> --target web
gamecraft-cli unity-import <unity-project> <output>
gamecraft-cli bake-lighting <project>
gamecraft-cli package search <query>

Running the tests

tools/quality-gates.sh     # everything
cargo test --workspace      # engine
npx vitest run              # editor
tools/linux-test.sh         # Linux, in Docker
