Frequently asked questions

If your question is not answered here, ask it in the issue tracker.

Is GameCraft free?

Yes. GameCraft is released under the MIT License. You can use it for commercial games without paying royalties or fees.

Do I need an account or an internet connection?

No. GameCraft runs entirely on your computer and does not collect usage data.

Can I open my Unity project?

You can import it. Scenes, prefabs, materials, animations, animator controllers, ScriptableObjects and .unitypackage files are converted to GameCraft assets, and an import report lists anything that could not be converted.

Will my Unity scripts work?

Scripts that use the supported parts of the UnityEngine API compile without changes. Scripts that use unsupported features fail to compile with an error naming the missing member. See Coming from Unity.

Do Asset Store extensions work?

Editor tools distributed as C# source and built with custom inspectors, editor windows, menu items or property drawers usually work. Most large extensions are distributed as compiled DLLs or use UI Toolkit, and these are not supported.

How are libraries and plugins loaded?

All scripts in your Assets folder are compiled into one assembly, and scripts in Editor folders into a second one. Packages are folders containing C# source and a package.json file. They are installed from a local folder or a registry after you review the permissions they request. Compiled .dll files and native libraries are not loaded.

Is GameCraft ready for a commercial game?

It is suitable for prototypes, game jams and small to medium projects. It is still in alpha: console export is not available, there is no asset marketplace, and no commercial games have shipped with it yet. Read the limitations before starting a large project.

Will GameCraft support consoles?

Console development kits are only available to developers accepted into each manufacturer's programme, and console code cannot be published openly. Support would be developed separately once access is granted. Xbox is the most likely first target.

Is it safe to open projects from other people?

Treat a project like any other program. Its scripts and packages run with the same permissions as the editor.

Is GameCraft related to Unity?

No. GameCraft is an independent project. It contains no Unity code or assets; it reads Unity's file formats and implements a compatible scripting API.
