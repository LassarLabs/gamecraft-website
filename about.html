About

GameCraft is developed by LassarLabs and released as open source.

Our approach

We think the tools people use to make games should work offline, store projects in open formats, and be free to inspect and change. GameCraft has no accounts, no telemetry and no license server.

Features are covered by automated tests, and the ones that are incomplete are documented in the repository. The test suite covers the engine, the editor and the platforms it exports to.

Contributing

Bug reports, feature requests and pull requests are welcome on GitHub. Before opening a pull request, run tools/quality-gates.sh and add a test for the behaviour you changed.
