Roadmap

What is finished, what we are working on next, and what is waiting on outside partners. Suggestions are welcome in the issue tracker.

  • In progress

    Polish

    • Rich text, scroll bars and world-space UI canvases
    • More particle modules, including sub-emitters
    • Blending between Timeline clips
    • 2D lights and gamepad vibration
  • In progress

    Automation

    • Live build sessions that keep running when the editor window is hidden
    • Scripted scene pipelines
  • Planned

    Releases

    • Signed and notarized macOS builds
    • Signed Windows builds
    • Automatic updates
  • Planned

    Community

    • A public package registry
    • Sample game templates
  • Waiting on partners

    iOS

    • Requires Xcode with the iOS SDK and an Apple Developer account
  • Waiting on partners

    Consoles

    • Requires acceptance into the PlayStation, Xbox and Nintendo developer programmes
    • Xbox is the most likely first target, since it uses DirectX 12
  • Done

    0.3

    • Unity project import and compatibility layers
    • Post-processing, global illumination and Shader Graph
    • Timeline, virtual cameras, GPU particles, mesh editing and rigging
    • Windows, Linux, Web, Android and OpenXR export
    • Package registry, Addressables, audio mixer, multiplayer and localization
